# Login Page

A simple login page with a fixed-credential check.

## Features

- Username and password inputs with a Login button
- Checks against fixed credentials: username `admin`, password `12345`
- Success message + alert on correct login, failure message + alert on wrong input
- Strict comparison (`===`) for both value and type

## Tech Used

HTML5, CSS3, Bootstrap 5, JavaScript (DOM, events, conditionals)

## How to Run

Open `index.html` in any browser. Try `admin` / `12345` for a successful login, and any other input to see the failure message.
